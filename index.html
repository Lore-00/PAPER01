Privacy and request usage

Your key is sent only to the API-Sports endpoint and is never embedded in this file. If you opt in, it is stored in unencrypted local browser storage on this device. Anyone with access to that storage or scripts on this website may retrieve it. Use only on a trusted device; forget the key to remove the saved copy. Clearing website data may also remove it. Each manual load normally uses one request. No automatic polling.
