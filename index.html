Privacy and request usage

Your key is sent only to the API-Sports endpoint and is never embedded in this file. If you opt in, it is stored in unencrypted local browser storage on this device. Anyone with access to that storage or scripts on this website may retrieve it. Use only on a trusted device; forget the key to remove the saved copy. Clearing website data may also remove it. Each manual load normally uses one request. No automatic polling.

Personal schedule

Select individual fixtures in the timetable. One estimated match-time reminder per time group, no repeats. Ignore or dismiss reminders whenever you are busy.

Requires the PAPER01 Reminders shortcut on your iPhone.

Setup and cancellation

Create an Apple Reminders list named PAPER01 and a shortcut named PAPER01 Reminders. The shortcut receives JSON with an events array containing title and date (ISO 8601). For each event add a timed reminder to that list. Confirm the reminders in Apple Reminders; clearing this shortlist does not cancel reminders already created. Delete those in Apple Reminders. Re-exporting may create duplicates.
